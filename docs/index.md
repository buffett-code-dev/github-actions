# github-actions

github-actions は、buffett-code-dev の各リポジトリのワークフローから使用する Composite Action を管理するリポジトリです。各 Composite Action の入力と使用例は、[リポジトリの README](https://github.com/buffett-code-dev/github-actions#readme) と、各ディレクトリの README を参照してください。

この docs/ には、複数の Composite Action と各リポジトリの設定にまたがる説明を記載します。

- [Claude Code による PR レビュー](./claude-code-review.md): 設定ファイルの場所と、モデルやプロンプトを変更するときに編集するファイル
